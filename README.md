# TravelBharat � Explore India State by State

A centralized tourism information platform for discovering Indian destinations state-wise and city-wise.

## Features

-  Browse 28 Indian states and 100+ destinations
-  Search & filter by state, city, and category
-  Image gallery with interactive maps
-  Admin dashboard for content management
-  Fully responsive mobile-first design
-  Secure JWT authentication

##  Tech Stack

**Frontend:** React 19, Vite 7, React Router, Tailwind CSS | **Backend:** Node.js, Express, MongoDB | **Deployment:** Vercel (Frontend), Render (Backend)
